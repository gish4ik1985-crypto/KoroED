# LYCTUS / KORoED

Браузерная аркада про короеда внутри дерева — по концепт-документу `LYCTUS rev.5`.
Открой `index.html` двойным кликом (без сборки и сети). Онлайн: включи GitHub Pages для ветки `main`.

## Суть
Дерево = зоны **Корни → Ствол → Ветви**, в каждой подуровни со своими входами и выходами.
Внутри — **сплошная древесина**: готовы только редкие старые ходы между гнёздами (маточные и личиночные ходы), всё остальное игрок прогрызает сам.
**Цель:** спасти личинок (нужно минимум 4 из 5) и вылететь из дерева, пока его не срубили (таймер).
Дерево неисследовано — карта открывается по мере прохождения, личинку «чуешь» стрелкой, когда она близко.

## Управление
- Стрелки / WASD / мышь (зажать) — ползти; упёрся в стену — прогрызаешь её
- **Shift** — рывок по готовым ходам (Крылья) · **Q** — замедлить время дерева (Голова)
- **Tab** — карта (маленькая в углу / большая / скрыта) · P / Esc — пауза · M — звук

## На телефоне
Держи телефон горизонтально (кнопка «⛶ На весь экран» на титуле). Коснись экрана и веди пальцем — это джойстик:
куда тянешь, туда жук ползёт и грызёт. Справа — кнопки «Рывок» и «Время», сверху — пауза, карта — нажатием на неё.

## Что есть из документа
- 3 дерева: **Трухлявая Сосна** (обучение), **Ель Обыкновенная** (смола, 2 слоя ствола, патруль, выбор входа),
  **Сибирский Кедр** (камень, 3 слоя, нахлебники, сильные враги, жёсткий таймер).
- Подуровни корней/ствола/ветвей, гнёзда без готового хода (за ними надо прогрызаться), секретные ветви, переходы между слоями ствола (⊕).
- **Враги с цветовой подсказкой:** зелёный круг — победишь, красный — беги. Неуязвимый патруль, нахлебники
  (блокируют ходы), дружественный короед (через время прогрызает ход к тайнику).
- **Дятел:** жёлтые зоны у коры — задержался дольше порога → предупреждение → удар. Уйти до удара = «ускользнул».
- **Няшки** (10 с): ⚡ ускорение, ⏳ время дерева ×0.3, ⚔ урон ×2, ❤ здоровье ×2, ✚ регенерация, $ монеты ×2.
- **Сундуки и секреты:** знаки частей тела (60%), монеты (33%), знаки короедов (7%); секретный знак на уровне.
- **5 короедов**, 6 частей тела (Лапки, Челюсти, Усики, Голова, Спинка, Крылья), прокачка за знаки + монеты.
- **Достижения** (серебряные/золотые знаки), **энергия на вход** (9 макс., +1 за 20 мин),
  проигрыш = половина награды, очки за остаток времени.

## Настройки
С титула и из паузы: звук (вкл/выкл, общая громкость, музыка, эффекты, фон), **язык (русский / English)**,
качество графики (быстрый режим для слабых телефонов), тряска экрана, мини-карта по умолчанию, стрелки-подсказки,
повтор обучения, справка по управлению, полный экран, сброс прогресса (с подтверждением).
Язык по умолчанию — по языку браузера.

## Что ещё есть
- **50 деревьев**: 3 из документа + №4–50 по шаблону (породы и регионы из документа, сложность по нарастающей).
- **Обучение** на первом дереве (11 шагов, можно пропустить).
- **Персонажи**: дятел у коры (прилетает, стучит, пробивает клювом ход), разные виды врагов, личинки в колыбельках, сундуки, катсцена вылета.
- **Звук**: хруст древесины разной плотности, стук дятла, фон дерева (гул, скрипы, птицы), мелодия в меню.
- **Ежедневный подарок** (7 дней подряд), **бонус за время в игре**, **бонусное дерево дня** (знаки «части тела дня»).
- **Магазин** за монеты (энергия, знаки) и **плюшки** перед забегом. Оплаты реальными деньгами нет.
